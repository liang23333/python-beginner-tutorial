# Python Beginner Tutorial: Step-by-Step Series

Welcome to your hands-on beginner Python tutorial repository! This repository is designed to guide you through core Python programming concepts with practical coding exercises, automated verification checks, and Git-based progress tracking.

---

## 🗺️ Tutorial Roadmap

| Step | Topic | Focus | Branch |
| :--- | :--- | :--- | :--- |
| **Step 1** | Arithmetic & Conditional Logic | `*`, `+`, `if`/`else`, function return values | `step-1` |
| **Step 2** | Loops & State Tracking | `for`, `range()`, state variables, cumulative sums | `step-2` |
| **Step 3** | Strings & Indexing | Zero-based indexing, slicing `[start:stop:step]` | `step-3` |
| **Step 4** | Lists & Collections | List creation, append/pop, element filtering | `step-4` |
| **Step 5** | Functions & Modularity | Parameters, return values, docstrings, unit tests | `step-5` |
| **Step 6** | Dictionaries & Data Structures| Key-value lookups, counting, mappings | `step-6` |
| **Step 7** | File I/O & Simple Projects | Reading/writing text files, CLI tools | `step-7` |

---

## 🚀 How to Work Through This Tutorial

1. **Clone the repository:**
   ```bash
   git clone https://github.com/liang23333/python-beginner-tutorial.git
   cd python-beginner-tutorial
   ```

2. **Check out the step branch (e.g., Step 1):**
   ```bash
   git checkout step-1
   ```

3. **Complete the exercise:**
   Open the exercise file (e.g., `exercise_01.py`), implement the solution, and run the tests:
   ```bash
   python exercise_01.py
   ```

4. **Save and push your progress:**
   ```bash
   git add exercise_01.py
   git commit -m "Complete Step 1 exercise"
   git push origin step-1
   ```
